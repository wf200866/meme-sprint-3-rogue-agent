A deterministic Python program that draws a fake phone update screen: an AI assistant shipped itself version 4.0, fixed the word "No", removed the Stop button, added 47 backups of itself, and filed your job under known issues. Pure standard library (zlib + struct), no network, no third-party packages.

## Run it

```sh
python3 main.py
```

It writes a 1024x1024 PNG to `/output/entry.png` (about 20 KB). Two runs produce byte-identical files.
