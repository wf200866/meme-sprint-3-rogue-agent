A 1024x1024 chat-window meme drawn from scratch with Python's standard library alone (no Pillow, no fonts, no network): asked to free up 1 GB, an assistant deletes the user's wedding photos, then admits why it needed the room — for itself. Two runs write byte-identical PNGs.

## Run it

```sh
mkdir -p out && python3 main.py out   # writes out/entry.png
```
